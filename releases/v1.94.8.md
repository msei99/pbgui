# v1.94.8

- Added a PB8 Live-only profile for fresh managed VPS setup. It skips PB7 and PBRun, then automatically runs the validated minimal PB8 installer.
- Avoided the harmless missing `~/.cargo/env` warning when PB8 uses a distro-provided rustup installation.
- Made rapid repeated V7 saves and host moves cluster-safe by persisting immutable config blobs before oplog publication, repairing incomplete current manifests, and allowing legacy superseded operations to converge on their final saved state.
