# v1.95.4

## Added

- Added a non-dismissible VPS Manager progress window for every **Add to Cluster** phase, backed by a reconnectable API job status.

## Fixed

- Kept VPS Manager Cluster onboarding running when its requesting page is closed, and show the stale pre-enable PBCluster result as **Checking** instead of **Error**.
- Used the authenticated remote Credential-v2 capability during initial and resumed Cluster joins so a fresh node is not mistaken for a post-cutoff protocol downgrade before its membership metadata syncs back.
- Pulled and validated a joined node's self-authored membership delta before pushing local operations, allowing interrupted joins to resume without weakening remote-ahead conflict checks.
- Allowed that delta pull without a new join grant only when the remote cluster and active checkpoint exactly match the locally verified active checkpoint.
- Staged newly pulled membership operations before validating deferred Credential-v2 ACKs from the same batch, matching the established PBCluster worker trust sequence.
- Kept joined Credential-v2 nodes resumable in VPS Manager until their materialization ACK is local, and added **Retry** to failed onboarding progress dialogs.
- Replaced a pre-join VPS placeholder's provisional role ancestry with its authenticated self-signed membership when the node becomes an active state replica, allowing its Credential-v2 ACK to validate after checkpoint-based onboarding.
- Included the authenticated local checkpoint baseline in remote-ahead push guards so compacted operations are not mistaken for unknown remote history during resumed onboarding.
- Kept VPS onboarding resumable for stale credential acknowledgements, rewrapped Cluster credentials for the joined recipient, materialized them remotely, and pulled the resulting current ACK back before starting PBRun.
