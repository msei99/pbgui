# v2.02.3

## Fixed

- Cluster Sync (#182): return reverse canonical replay order using numeric actor-local sequences and remove the redundant snapshot rebuild. Identity and validated operation loading now share the checkpoint/history lock. Only genuinely absent or empty cluster roots yield empty history; retained state with missing identity, symlinks, malformed JSON and checkpoint/I/O failures produce logged HTTP errors.
- Cluster Sync (#183, #185, #186, #187): display targets for every current operation family, isolate Oplog polling failures, bind retention and Bootstrap confirmations to their preview generation, and keep retention reporting fail-closed when local cleanup diagnostics fail.
- Cluster Sync (#188, #189): prevent removal of nodes that still own PB8 configs; expose separate PB7/PB8 desired-state and tombstone tables, PB8 capability badges, generation-bound lifecycle actions, and local PB8 Bootstrap publication.
- VPS Monitor (#192): preserve PB7/PB8 runtime identity for same-named bots and show PB8 version drift plus fresh stopped/disabled observations without inventing rows from stale snapshots.
- PB8 Run (#191, #193): add stopped-only atomic rollback of complete immutable backups, preserve monotonic Cluster publication, resolve the last active host for stopped bots, and retain available supervisor/runtime logs for authenticated smart-history fallback.
- PB8 Backtest (#194): use the canonical `/ws/bt8` queue route while retaining `/ws/bt7` as a compatibility alias.

## Issue Review

- #171: current Hyperliquid documentation confirms PBGui's delegated `agentSendAsset`/L1 Agent signing flow with chain ID 1337. No protocol change was applied; the separate nonce race was fixed in v2.02.2.
- #182: production operation IDs encode actor and sequence. The explicit numeric replay key primarily protects sequence counters after they exceed their historical fixed width while avoiding the redundant materialization pass.
- #184: `oplog` is an intentional legacy alias for full automatic retention (`oplog_and_blobs`), not a separate supported policy. The UI continues to show and save the canonical mode.
- #194: the PB8 WebSocket naming fix is included. The proposed extraction of the legacy PB7 archive controller is intentionally not pursued because PB7 is no longer under active development.

## Validation And Limitations

- Added isolated regression coverage for Cluster history ordering and failures, optimistic generation guards, PB8 state/bootstrap/lifecycle, PB8 backup rollback and historical logs, VPS runtime identity, and PB8 WebSocket routing. Relevant English and German guides are updated.
- Final offline release suite: 7,517 passed and 41 skipped. Focused validation for all changed areas passed 510 tests.
- PB8 rollback and delete remain fail-closed: relevant local and remote runtime state must be verifiably stopped before mutation. Missing, stale, or ambiguous observations return HTTP 409.
- No bot/VPS host was deployed, updated, restarted, or otherwise modified during development.
