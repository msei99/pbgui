# v2.0

## Added

- Added the profit-sweep policy, private SQLite ledger/state store, high-water-mark dry-run calculation, simulation journal, and offline coverage.
- Added crash-safe Live profit sweeps for Hyperliquid, Bybit, Binance, and Bitget with durable intent reconciliation, Vault transfer legs, automatic unknown-state pausing, and authenticated intent APIs.
- Enabled the Profit Sweep Live UI with explicit baseline and catch-up activation choices, one shared safety confirmation, exchange-specific routes and assets, capability diagnostics, durable intent states, and unknown-intent reconciliation.
- Added authenticated non-Vault Profit Sweep test-transfer roundtrips with fixed reverse exchange routes, isolated persistence and accounting, strict reconciliation, and durable unknown results.
- Added Profit Sweep Test transfer and confirmed-only Transfer back controls with real-funds confirmations, generation-safe operation status refresh, Vault guidance, and complete bilingual operating documentation.
- Added Hyperliquid Vault test-transfer roundtrips using a conservative leader-owned withdrawal cap, reconciled net withdrawal amount, and an exact Main Perps-to-same-Vault deposit return.
