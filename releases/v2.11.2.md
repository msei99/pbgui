# v2.11.2

- VPS cleanup removes PB8 runtime directories, monitor data and run logs for bots without a configuration or process after a seven-day grace period. It also removes unused data and logs under PB8's legacy `None` root.
- Previous-run logs for configured PB8 bots expire according to each bot's `monitor.retain_days` setting (7 days by default). The current run and its rotated files remain available. The cleanup queries only this setting from each bot config.
