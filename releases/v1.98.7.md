# v1.98.7

## Fixed

- Fixed PB8 Backtest `Add to Run` handoffs taking several seconds before navigation and then rebuilding the editor in visible stages; canonical result configs now become Run drafts without a redundant PB8 subprocess, the final field layout renders directly from the draft while metadata/users load independently, and early Save clicks wait for editor initialization instead of reporting an empty Raw JSON error.
- Prevented PB8 live configs from targeting hosts whose reported PB8 config schema is older than the config; incompatible hosts are omitted from the editor selector and the save API rejects stale-runtime assignments.
