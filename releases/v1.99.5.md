# v1.99.5

## Added

- Added explicit pre-save Backtest conversion decisions for V7-compatible WEL excess sizing and PB7-versus-PB8 minimum coin-age semantics.
- Added a persistent, isolated, lifecycle-managed PB8 migration helper with startup prewarming and immediate centered conversion progress messages.
- Added a global AI page catalog and cross-page control activation by stable labels; all rendered non-sensitive PBGui buttons, links, selectors, inputs, delegated actions, and keyboard controls are now discoverable beyond the current viewport.

## Changed

- Changed PBv7 Backtest, Run, Optimize, and Pareto conversions to open unsaved PB8 previews; config bundles and migration reports are now persisted only after an explicit user Save or Save & Queue.
- Changed mixed PBv7/PBv8 result tables to compare unweighted USD ADG, Sharpe, and drawdown by default, with weighted PBv8 variants available as optional columns.
- Changed successful PB8 updates to restart managed PB8 live bots only after CLI, Rust, schema, and fingerprint validation completes; failed updates leave the existing process untouched.

## Fixed

- Filtered strategy-incompatible optimizer overrides, canonicalized fixed-runtime paths, froze disabled search sides, and preserved implicit positive-threshold V7 WEL/TWEL enforcers during conversion.
- Preserved migration reports and canonical HSL runtime overrides through preview saves, while keeping context-irrelevant findings non-blocking.
- Removed repeated PB8/Pymoo/CCXT cold starts and config-list flashes from conversion navigation; warmed migrations complete in measured sub-100 ms time.
- Removed stale suite scenarios for exchanges removed from a PB8 Backtest config, preventing successful selected-exchange runs from being accompanied by unrelated exchange errors.
- Added bounded exact-process escalation for remote PB8 restarts so a shutdown `BrokenPipeError` cannot leave the old bot running while PBGui reports success.
- Fixed inactive-strategy coin-override metadata, pre-backup Cluster rollout blocking, disabled AI select options, automated confirmation-dialog access, and the PB8 branch-update playbook syntax.
