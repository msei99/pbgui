# v2.07 — Shared page layout and service responsiveness

## Consistent navigation and sidebars

- Standardized sidebar spacing, buttons, inputs, selected states and semantic action colors across PBGui. Sidebar width is draggable, keyboard-accessible, stored once per browser and restored across pages.
- Fixed clipped content on narrow screens, pointer loss when dragging over embedded frames, and resize state after window focus loss. Long labels wrap and long action lists remain accessible.
- Added the shared sidebar to Hyperliquid Limits and Balance Calculator. Limits retains all table columns and shows selected-account history above the table; calculator controls sit beside editors/results that adapt to the available width.
- Converted Information → Help into a full-page topic browser with a resizable sidebar. Topic, language, filters and search state survive reload. Guide remains a floating window, including on the Help page. Updated the menu cache version and verified the actual menu path.
- Restored compact Dashboard action icons and compact EN/DE language buttons using the shared icon-row variant, avoiding horizontal overflow.
- Removed redundant manual refresh controls from the affected Services Workers and Run views; automatic updates remain active.
- Added a mandatory design guide linked from AGENTS.md, with shared layout examples and checks for real menu navigation, dynamic controls, overflow, state restoration and cache delivery.

## Services and VPS Manager

- Fixed the missing Restart button caused by a JavaScript helper being outside the scope of the status renderer.
- Services overview now reads lightweight live worker state without scanning queue configurations. Detailed synchronous worker inspection and restart-status scans run outside the API event loop.
- Services overview renders its loading state immediately and avoids duplicate initial status requests.
- Balanced the VPS Manager master status grid, improved resource-meter spacing and made collector-loop tables readable on narrow screens.
- Clarified Monitor Agent Cache diagnostics with separate **Cache files** and **Collector loops** headings. Both are retained because file presence/validity/age and collector execution/error state convey different information.

## Backtest and GPU workflows

- Backtest Results can select multiple collapsed Optimize validation groups, including hidden results, for bulk deletion.
- GPU & Offers highlights exact GPU-model/machine matches with confirmed rental history and real optimizer runs. Manual Working marks remain separate from observed execution evidence.
- Kept completed GPU proxy counts visible when PB8 emits CPU exact-progress events during the following GPU batch.
