# v2.09.10

## Fixes

- CMC key deletion now stays locked through confirmation, deletion and the required fresh snapshot, including overlapping credential changes. Successfully deleted keys remain unavailable across navigation and failed reads until a current snapshot succeeds. Automatic updates replace manual Refresh controls while preserving other selections, edits and table scroll. Cancelling confirmation restores Delete focus when appropriate without disrupting newer dialogs or focus changes. Failed mutations are not automatically retried.

- VPS Manager now keeps Save Log Settings locked until its matching reply, timeout or disconnect, preserves unsaved drafts across updates and view changes, and ignores stale replies. Delayed feedback preserves newer dialogs, input and focus, using a toast while a dialog is open and the normal error modal otherwise. Saves are never queued or automatically retried.

- HL Limit charts now report automatic history update failures in the subtitle and browser console while retaining cached data and input. Updates time out after 15 seconds, ignore cancelled or obsolete results, and restore the normal subtitle after recovery.

- VPS Manager now reports current Master and VPS detail loading failures with deduplicated, dialog-safe notifications and console logging. Cached data, edits, focus and pending actions are preserved, and stale failures are ignored. Unavailable hosts return to Overview with reload-safe navigation. Affected manual refresh controls now use automatic updates, and notification-log links work under mounted paths.

- Cluster onboarding now prevents repeated starts and retries while an operation is pending, ignores obsolete responses and timers, and offers Retry when a start returns no valid job ID. Returning to a host correctly resumes its active onboarding job after an interrupted lookup.

- Blocking Cluster snapshots and affected local file operations now run in worker threads for retention reports, immediate V7 sync, credential rewrap and VPS onboarding, improving API responsiveness. Locking, durable retries, onboarding serialization and restart protection remain in place through cancellation and shutdown. Concurrent pulled config publications now use separate temporary files, preventing collisions and preserving committed content on failure.
