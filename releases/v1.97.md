# v1.97

## Added

- Added PB8 Branch Management for local and remote VPS Manager hosts, including validated branch/commit switching from upstream or custom remotes while normal PB8 updates continue to restore the verified upstream master.
- Added clickable Linux update details in VPS Manager with package names, installed and candidate versions, new dependencies, planned removals, apt source, and Security/Kernel/Routine urgency guidance; incomplete package lists remain explicitly unclassified.
- Added a dedicated PB8.1.0 integration plan covering new config fields, lossless Optimize handling, collision-only exact PB8 market IDs while retaining short coin names as the default, typed coin overrides, tests and guides, with Bitunix and WEEX scheduled last as a low-priority delivery that includes Dashboard support.

## Fixed

- Kept VPS Monitor SSH connections and remote log streams alive across ordinary API restarts by moving their ownership into a dedicated local systemd daemon with an owner-only Unix RPC boundary.
- Restart active PBData services during master PBGui updates so they do not keep running outdated code after the API restarts.
