# v2.02.2

## Fixed

- VPS Manager: fetch today's bot errors from all monitor-discovered log files in bounded batches. More than 32 archived sessions no longer cause an empty error dialog through monitor RPC or omit newer files through direct reads after a restart.
- Balance Calculator: prevent inline-script injection, enforce draft expiry, validate PB7/PB8 config-file inputs and numeric sizing parameters, resolve symbols through canonical market mappings, and retain full precision through balance recommendation selection (#173-#179, #190).
- Profit Sweep: serialize policy saves with active account operations and startup recovery; add targeted test-transfer reconciliation and explicit, evidence-gated return retries without resubmitting unknown transfers (#164-#166).
- Hyperliquid transfers: coordinate persistent nonces by actual signer across local processes, bind prepared transfers to that signer, and correct concrete return-route validation and confirmation labels (#163, #172).
- DB Tools: create bounded, WAL-aware remote backups with UUID names and atomic no-clobber publication; existing snapshots and symlinks survive collisions, failures and cancellation (#170).
- DB Tools: reserve destructive maintenance exclusively from backup through completion, verify PBData shutdown, and coordinate Database/PBData writers. Bundle restores prepare all snapshots first, restore in place, and roll back partial failures. Durable recovery journals and remote outcome receipts block unsafe writes/restarts until interrupted operations are reconciled. Remote maintenance commands are never automatically resubmitted after uncertain transport outcomes (#168, #169).
- Cluster Sync: serialize history replay and complete snapshot publication, validate snapshots against operation/checkpoint history, and recover stale or interrupted multi-file snapshots instead of accepting newer timestamps on older state (#181).
- Balance Calculator, Profit Sweep, Transfers and Cluster Sync: preserve ASGI mount prefixes and IPv6 through API/WebSocket URLs, page assets and shared navigation/authentication links (#167, #174, #180).

## Validation And Limitations

- Added isolated regression coverage for HTTP input validation, hostile HTML, numeric boundaries, mapping aliases, transfer idempotency, credential rotation, cross-process nonces, database rollback and crash recovery, lost SSH responses, cluster publication races, mounted pages and navigation. Relevant English/German guides are updated.
- Final release offline suite: 7,461 passed, 41 skipped. Unrelated local OpenCode tooling and its 10 tests are not part of this release. Source review found no remaining blocker in the included fixes.
- Preserve the documented Hyperliquid agentSendAsset/L1 signing protocol with independent offline contract vectors. The protocol replacement proposed in #171 is not supported by current upstream documentation and was deliberately not applied; a concrete provider rejection is needed to investigate that claim further.
- Reload the API and PBData before using the new database maintenance protection, and let older detached sync workers finish. Remote targets must also run the updated writer guards; unsafe older target versions are rejected rather than updated automatically. No services or remote hosts were changed during development.
- Interrupted DB maintenance remains blocked until explicit recovery reconciles the durable journal or remote receipt. This is recoverable multi-file maintenance, not one crash-atomic SQLite transaction across both databases. External SQLite writers that bypass PBGui coordination remain outside these safeguards.
- Hyperliquid nonce coordination covers local processes sharing the state directory, not independent hosts or external bots using the same signer. Existing transfers with unknown outcomes are never blindly resubmitted. Old prepared descriptors without signer binding remain available for reconciliation but cannot be re-signed.
- Real exchange transfers, browser/proxy smoke tests, and remote-host failure tests were not performed. The separate new issues #182-#189 and #191-#194 are not included in this bugfix release.
