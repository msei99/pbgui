# v2.05.5

- VPS Manager shows the Hyperliquid address request usage directly in each mapped PB7 or PB8 bot row before CPU. The usage percentage sits above the actual Used/Cap counters; clicking opens the existing 24-hour history. PB7 bot names are resolved through their saved exchange user, and matching keeps PB7 and PB8 identities separate.
- VPS Monitor keeps fresh CPU, RAM, and swap readings when a bot metadata snapshot arrives, preventing brief false recovery and repeated threshold alerts.
- Without custom monitor settings, PB7 bot CPU warning/error thresholds are 15%/20%. The RAM error threshold remains 500 MB.
