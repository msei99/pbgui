# v2.07.3 — Balance database and sync fixes

## Fixed

- Preserve existing balance row IDs when PBData refreshes balances and when DB Sync updates selected users. This avoids repeated delete/insert cycles and prevents source row IDs from colliding with unrelated local users.
- Verify append-only DB Sync tables without treating retained local history rows as a failure. State tables still require matching counts and latest timestamps.

## Validation

- 166 focused offline tests passed across the DB Tools, dashboard regression and release modules. The test-suite gate selected focused validation for this patch release.
- On the repaired local database, a complete sync finished successfully and SQLite `integrity_check` returned `ok`.
- The local database was repaired separately from this code release; installing the release does not repair an already corrupted database.

## Upgrade

Restart the PBGui API and PBData through their normal controls after updating. This release does not update or restart any remote bot/VPS host.
