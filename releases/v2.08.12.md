# v2.08.12

## Improvements

- Add AI Loop evidence for ChatGPT and OpenCode: fresh isolated decisions, bounded compact findings, exact current safety/goal evidence, immutable paged archives and complete recovery after context compaction. Support available models from 256k with automatic context discovery during normal decisions.
- Support native or JSON-message evidence readers across OpenCode chat/completions, Responses and Messages. Negotiate unsupported streaming/tools from actual requests and cache observations automatically. Keep finite inactivity/nonstreaming limits, cumulative context checks and per-call accounting. Existing paid Zen spend limits and uncertain reservations remain.
- Show provisional AI/source/archive/cost previews and editable recovery limits. Resume validates the chosen provider's actual payload and original evidence checksums before unpausing; capability, context, cost and storage conditions use diagnosed recoverable pauses.
- Derive visible native Pareto archive limits for new Loop jobs, read all available artifacts and historical sources, and preserve native objective extrema. Historical advice stays optional; unsafe or oversized sources remain archived and can fall back to a fresh bootstrap.

## Fixes

- Preserve provider-reported native tool metadata in the projected OpenCode model list so Loop capability preflight receives the catalog's real value.
- Keep previews read-only and provisional until the normal ChatGPT response reports its window. Show **Reported by normal response** and report insufficient context explicitly.
- Safely dispatch optional Loop callbacks. Learn actual ChatGPT context through the normal decision chat/notification reader before committing a winner.
- Bind evidence snapshots and ledgers to the actual decision input so new JEV results and controller repair feedback reach the model. Preserve uncertain usage and cumulative authorized spending across evidence revisions.
- Learn context and transport settings automatically from provider metadata and normal replies. Ignore missing or damaged optional telemetry caches.
- Expire cached transport fallbacks after 24 hours, independently per transport feature, and preserve both recovery dialogs when switching to the JSON reader. Report unavailable context settings as `context_budget`.
- Reuse complete JSON replies when a provider ignores requested streaming and use nonstreaming for subsequent requests in the dialog.
- Apply the interpreted rubric to the first native archive allocation and include the complete provider envelope and initial reserve when selecting bootstrap advice. Handle malformed complete OpenCode tool arguments as native tool errors, process streaming deltas without repeatedly encoding the growing transcript, and report exhausted contract recovery accurately.
- Sweep ended-loop snapshot retention from the registered controller, preserve interrupted evidence, cache skipped native-source archives and enforce explicit HSL off/on/auto policy for older saved instruction versions.

## Documentation

- Document available models from 256k, automatic context/transport handling and current runtime behavior in the EN/DE help.

## Known limitations

- Snapshot expiry for completed Loops currently counts 14 days from snapshot creation rather than Loop completion; snapshots of deleted Loops are not swept.
- Live ChatGPT compaction recovery previously used a one-page mandatory package; larger recovery packages are covered offline. Provider outages, missing actual context and hard workload/budget limits can still prevent progress.
