# v2.02.17

## Fixed

- Fixed parallel VPS Linux updates being reported as failed after reboot when the restarted monitor agent and the update playbook refreshed the same apt cache concurrently, and allowed remote apt tasks to wait longer for `unattended-upgrades`.
- Fixed the global restart action overlooking a running VPS Monitor that lacks newer RPC methods, which left actions such as `Check Linux Updates` unavailable after restarting PBGui.
- Fixed Pareto `Training + Holdout + Full timerange` validation being disabled for Suite results without persisted Holdout provenance; available Training and Full jobs can now still be queued with an explicit skipped-Holdout warning.
- Fixed related Optimize validation Training, Holdout, and Full results being split into separate groups when PB8 emitted period-specific metrics or narrowed Suite exchanges.

## Validation And Limitations

- Focused offline API, monitor, VPS update, PB8 Backtest/Optimize frontend, help-coverage, and release tests: 529 passed.
- No PB7/PB8 bot code was changed, and no bot or VPS host was modified during development or release preparation.
