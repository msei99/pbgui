# v2.08.16

## Fixes

- AI Loop follow-up experiments must make a material change to search bounds, effective scoring objectives/basis, or optional search filters. Seeds, mutation-only tweaks, ordering, duplicates, labels and step-only edits do not satisfy the check. Every material proposal must explain its search hypothesis.
- After two rounds without improvement, the next experiment must differ materially from all previously tested searches. The AI receives a compact history of experiments and exact training candidate results; Human Observer reports remain excluded. Hard user-goal filters and independent CPU winner qualification remain protected.
- Invalid proposals enter bounded correction before another optimizer attempt is created or the evaluation is committed. First experiments, final evaluations and completely fixed legacy searches remain supported.
- Automatic GPU population selection no longer falls back to the worker's 1,024 default when an AI follow-up retains explicit validation/drift settings. PBGui resolves population from the current hardware, calibration or rental profile while preserving those settings. The RTX 3060 regression retains population 8,192 and the 128:1 proxy/exact ratio across rounds. Explicit sizing, disabled Auto and short-run safeguards retain their existing behavior.

## Learning and documentation

- Owner-scoped learning reset support archives the knowledge index and excludes pre-reset archived findings from future AI context. Reset epochs invalidate old decision/snapshot reuse. Original runs, immutable evidence and used/reserved Holdout accounting remain intact; all owned Loops must be terminal before reset. Updating PBGui does not automatically reset learning.
- Updated English and German Loop and Vast GPU guides.

## Validation

- Test-suite gate: focused offline checks only. Combined release validation: **1,152 passed**. Whitespace checks passed.
- No real rental, optimizer or remote bot operation was started by release validation. The timing fix is covered by an isolated two-round configuration regression; real GPU timing after this fix has not yet been measured.
- API serial 3263 exposes the release restart requirement.
