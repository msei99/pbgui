# v1.98.26

## Fixed

- Optimize editors now expose the missing Apply Filters action, applying market-cap, volume, tag, CPT, and notice filters across selected exchanges to both Long and Short approved/ignored coin lists.
- Run editors now use an explicit Apply Filters button instead of a transient checkbox; PB8 clearly marks `dynamic_ignore` as unsupported, removes stale flags on save, and keeps resolved coins when some filtered symbols are unavailable.
- Delayed API restart units now disable systemd environment expansion, preventing combined PBGui/runtime updates from killing their own active Ansible and PB8 installation processes.
- VPS Manager now detects incomplete PB8 installations and updates through the runtime-invalid marker, preserves installed-checkout semantics, and highlights the required PB8 repair in Overview, host details, and sidebar actions.
- PB8 Run now distinguishes a shared PB8 runtime failure from an invalid individual config, displays the exact cause in the Status column, and provides a persistent VPS Manager update action when runtime repair is required.
