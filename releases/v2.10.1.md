# v2.10.1

## Upgrade notes

- Update the versioned Python requirements in the existing PBGui environment through the normal installation/update workflow. Claude now uses the official Python Agent SDK and its bundled native client; no Node.js/npm installation or separate provider environment is required. Existing Claude subscription sign-in profiles are retained.
- Project-owned browser tests use a locally installed Chromium browser and `requirements-test.txt`; Playwright/Node test drivers are no longer required.

## Fixed

- Resume paused AI Loops with an interrupted request on the first acknowledged attempt. Recognize pending reservations in polling, retain their usage and audit history, and prevent a retry while the previous controller step is still stopping.
- Keep credential migration process scans working when unrelated argv contains a literal tilde with no resolvable home directory, while retaining checks of all arguments in PBGui-owned processes. This prevents a completed migration from incorrectly blocking local API restarts.
- Measure Coin Data detail-card constraints before opening and populating the card, avoiding an unnecessary first layout while preserving immediate selection and content fitting. (#419)
- Preserve the Orders chart's exact right offset during continuing live updates, while retaining label-margin adjustment for manual follow resumption, resizing and density changes. (#443)

## Changed

- Replace the Claude Node/npm worker with the official Python Agent SDK installed in PBGui's existing Python environment. Keep private native account profiles, PBGui capability approval, model/context discovery, structured Loop decisions, streaming and cancellation. (#445)
- Update compatible FastAPI, Starlette and Pydantic versions for the Python SDK's MCP dependency.
- Validate the preserved Host header directly for browser same-origin checks, retaining fail-closed rejection of malformed authorities after the Starlette update.
- Enforce Python/FastAPI and browser Vanilla JS as the project-wide architecture, including installation, development and test tooling; document the Node/npm removal audit.
- Replace Node-based JavaScript checks and the Playwright driver with direct Python-to-Chromium browser testing. Preserve the existing behavioral assertions, synthetic API routes and isolated profiles; block unhandled browser traffic.
- Remove repository-local GitNexus configuration, generated tooling and bootstrap instructions; use a conservative Python AST call/import inventory with explicit dynamic-call limitations instead.
- Keep the Orders viewport browser scenario's pan outside the label-dependent follow margin when using native input; retain all exact range, zoom, history and automatic-update assertions.
