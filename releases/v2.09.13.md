# v2.09.13

## Features

- Added optional exact Pareto stagnation stopping for local PB8 CPU/PyMoo and GPU optimization, independent of Vast.ai rentals. Settings persist in queue snapshots and Results checkpoint resumes, including native configs without PBGui metadata. Logs show warmup, improvements, patience and waiting or unavailable reasons. Compatible observation history survives output renames and budget or CPU changes without counting restored results twice, including migration of existing compatible history. Invalid result-owned settings are rejected before queue creation. GPU detection includes background-collected Rust results and prevents duplicate stop requests. Successful native cleanup records convergence and actual final evaluations, retaining available results and already safe native checkpoints. Manual interrupts, cleanup errors and watchdog escalation remain failures; escalation still cleans up verified processes if its status cannot be recorded. Existing Vast.ai convergence and behavior with local stopping disabled remain compatible. (#444)
