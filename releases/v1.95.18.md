# v1.95.18

## Added

- Added Pareto Explorer `coverage` candidate selection for evenly sampled optimize-history alternatives alongside top-ranked metric strategies.

## Fixed

- Added persistent checkpoint caches for diff-compressed PB8 Pareto results, eliminating the second full-file pass and making later loads fast across API restarts.
- Invalidated persistent and in-memory Pareto caches when the source file identity changes, and rejected results modified during a full scan.
- Kept the API responsive during multi-gigabyte Pareto Explorer `all_results.bin` scans by cooperatively yielding between msgpack and checkpoint-reconstruction batches.
- Clarified Pareto Explorer full-mode counts so scanned source records, selected candidates, and the visible range are reported separately.
- Avoided presenting saturated single-scenario robustness scores as evidence of consistency or candidate diversity.
