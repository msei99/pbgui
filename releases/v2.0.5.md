# v2.0.5

## Added

- Added PB8 Apple-MPS GPU integration with selectable editor preview on unsupported hosts, runtime capability gating, native queue/start preflight, typed GPU and Successive Halving controls, backend-specific metric choices, structured GPU progress, stronger checkpoint compatibility, required-dataset Suite readiness, and optional `gpu-mps` installation on supported hosts.

## Fixed

- Let the restart overlay automatically finish services first discovered as outdated after the new API process starts, instead of waiting indefinitely after an upgrade initiated by the old process.
- Render GitHub Telegram release notes as safe HTML instead of exposing raw Markdown markers such as `##` and `**`.
- Keep AI conversations and retryable prompts available when an idle or failed ChatGPT runtime releases its ephemeral thread.
