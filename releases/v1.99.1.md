# v1.99.1

## Added

- Added API-owned hidden continuation turns so successful proposal approvals automatically resume multi-step AI workflows in the same conversation.

## Behavior

- Continuation starts only after an action returns `status: executed`; rejection and failed execution do not continue.
- Internal continuation instructions are delivered to the model but removed from visible browser history after use.
- If no requested workflow step remains, the model is instructed to confirm completion without creating another proposal.
