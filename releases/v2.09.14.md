# v2.09.14

## Fixes

- PB8 Optimize reconciles Raw JSON and form edits before date lookup, Readiness, Save and Queue, preserving separate changes and applying the latest field edit. Invalid JSON remains editable without entering config or draft storage. Updates preserve cursor position and coherent valid drafts and reject stale results (#496).

- PB8 Optimize lists saved Configs before loading backtest counts and automatically updates metadata and counts while preserving search, sorting, selection and drafts. Pending and unknown counts are explicit. Default API callers retain result summaries and wait for complete, verified counts; unsuccessful verification leaves counts unknown (#495).

- PB8 Optimize preserves safe, actionable lookup errors through helper responses, job status, logs and the start_date message, including missing HSL restart policies for Long, Short and portfolio scopes. Unknown diagnostic codes receive a generic fallback without exposing exception text, paths or configuration contents. Diagnostics preserve dates and timestamp selection; adjusted-field counts are informational (#496).

- PB8 Optimize exposes Long/Short and existing Unified portfolio HSL restart policies as form selects. Relevant unresolved policies default to always, while valid never choices and effective overrides are preserved. Date lookup, Readiness, Save and Queue use consistent values without Raw JSON editing. HSL activation, absent HSL objects and unrelated edits are preserved, and restart/lookback help is corrected (#496).

- PB8 Optimize restores unsaved named-config drafts from the existing credential-filtered tab store after checking current server access. Restart selects retain focus during redraws, label help supports keyboard access, and Escape dismisses the tooltip while keeping the editor open (#496).

## Limitations

- Backtest count scans now stop at 10,000 visited filesystem entries; the previous limit counted matching analysis.json paths. Previously countable folders can therefore return unknown. Safety or resource limits also leave counts unknown rather than publishing partial counts or treating incomplete scans as confirmed zero. Cooperative scan budgets cannot interrupt a blocked filesystem call (#495).

- The original live start-date lookup failure’s exact cause remains unconfirmed. Offline coverage uses synthetic PB8 preparation, coin formatting and market timestamps (#496).
