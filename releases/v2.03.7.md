# v2.03.7

## Fixed

- Support PB8's experimental NVIDIA CUDA optimizer on Linux/WSL2 using the installed PB8 device selector, with CuPy/NVRTC checks before Queue or Start and compatibility with older Apple MPS runtimes (#325).
- Include GPU metric aliases accepted by PB8, including `long_short_profit_ratio`, in editor choices without enabling unsupported or exact-only metrics.
- Report failed Logging Monitor GET requests instead of applying fallback rotation settings or displaying an empty log list; preserve HTTP status for non-JSON errors (#321).
- Require confirmation before deleting Hyperliquid job history and logs, block duplicate deletion requests, and refuse deletion when the dialog is unavailable (#308).

## Changed

- Select optional GPU dependencies on the installation target: Apple MPS, NVIDIA CUDA when a working driver and compatible PB8 revision are detected, or CPU full profile. Keep VPS live-only profiles unchanged and allow explicit Ansible GPU profile selection.
- Show the detected GPU runtime and NVIDIA device name in Optimize; clarify Apple-specific tuning and update the EN/DE guides.
- Recover and refresh the GitNexus index after an incomplete incremental update.

PBRun's automatic bot restart policy remains unchanged. NVIDIA hardware execution has not been validated in this release's offline checks.
