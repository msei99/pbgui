# v1.96

## Added

- Added PB8 Strategy Explorer to the shared PB7/PB8 GUI, with runtime-derived editable strategy controls and Optimize-bound highlighting, native supplied-state ideal-order snapshots, bounded native replay, stored-result and pinned Pareto-candidate comparison, Movie Builder candles and fills, and Run, Backtest, Pareto, and navigation handoffs.
- Isolated PB8 Strategy Explorer calculations in bounded, cancellable PB8-venv helper processes with owner-bound opaque drafts and progress records, validated result provenance, stale-operation-safe progress IDs, and deterministic API shutdown.
- Added PB8 Run, Backtest, result, and Pareto handoffs that preserve referenced sparse coin overrides in owner-bound drafts; Pareto handoffs now report unavailable or malformed overrides instead of opening an incomplete Strategy Explorer comparison.

## Security

- Secured the shared PB7/PB8 Strategy Explorer by removing rendered session bearer tokens, using same-origin HttpOnly-cookie authentication, and script-escaping inline draft IDs, result paths, API bases, version, and serial values to prevent bootstrap-script injection.
- Limited Movie Builder exports to one shared encoder job at a time, rejected PB8 export payloads over 16 MiB and encoded outputs over 512 MiB, and returned explicit HTTP 413 or 503 responses for oversized or busy exports.

## Fixed

- Fixed PB8 backtest-result handoffs to select the result dataset's actual source exchange, first-fill coin and timestamp, and each strategy side's required geometric EMA span so native OHLCV and Rust orders load correctly for combined results.
- Fixed initialized PB8 Strategy Explorer pages to keep recalculating config-based snapshots after their short-lived handoff draft expires or an API restart clears it, while retaining strict draft ownership for stored-result comparisons.
- Fixed PB8 stored-result comparisons to honor the fills range, align replay startup one configured candle before the first fill, filter stored fills to the exact replay window before applying limits, and classify timestamp-separated events without false index-paired mismatches.
- Fixed the Movie Builder plot container height so Plotly's built-in Play, Slow, Very Slow, Pause, and frame-slider controls are visible immediately without entering fullscreen first.
- Fixed PB8 Movie Builder fills to avoid browser-local-time shifts, preserve full entry/close order-type classification, and aggregate complete step-sized OHLCV bars; historical native order ladders remain unavailable, and any entry/close lines shown in the movie are fill-derived previews rather than reconstructed resting orders.
- Fixed PB8 Strategy Explorer parity and safety across full-config round trips, asymmetric Long/Short market selection, exact Analysis Time metadata, replay-candle plotting, unsupported manual start state, approved OHLCV source roots, genuine Compare source requirements, exchange-step fill matching, and partial stored-fill coverage warnings.
- Fixed PB7/PB8 Optimize result switching to clear the previous Pareto rows, metadata, and selections immediately before loading the newly selected result.
- Improved Movie Builder inspection with exact price hover text on dashed entry/close lines and paused one-frame navigation using the left and right arrow keys.
- Fixed PB8 Strategy Explorer browser refreshes to restore a non-sensitive tab-scoped config, active section, Movie controls, and bounded generated Movie data after draft expiry or an API restart, without storing credentials, authentication tokens, or result paths.
- Fixed restored Movie Builder charts to select the cached section before Plotly initialization and recalculate chart width after becoming visible, avoiding the Analysis-page flash and narrow refresh layout.
- Fixed PB8 Strategy Explorer handoffs without usable local candles to retain a renderable config and tuning view with an explicit snapshot-unavailable message instead of leaving the page blank.
- Fixed stale-response races across Strategy Explorer and Pareto Explorer so config or result changes invalidate earlier market, snapshot, simulation, comparison, movie, detail, preset, playground, command-center, deep-intelligence, and background-load responses before they can overwrite the current selection.
