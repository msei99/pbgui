# v2.10.9

## Improvements

- Extend OpenRouter beyond Jev with searchable chat models in AI Setup and Chat, including streaming, images and catalog-advertised reasoning settings (#447). Apply existing conversation, output and tool limits; validate complete replies and tool-call batches before executing tools. Show safe provider and routing errors without switching models automatically.
- Add a shared OpenRouter model browser with List/Table views, search, type and variant filters, pins, descriptions, release dates, context and input/output prices. Table headers sort prices and dates correctly; browsing state survives reload. Hidden search fields never filter small catalogs when switching providers, and unavailable or filtered-out selections remain explicit.
- Require a successful synthetic tool roundtrip before enabling PBGui tools for an OpenRouter model. Approval is scoped to owner, key and model version, checked before each call and removed on connection changes or new model versions.
- Keep provider data collection blocked by default. An explicit privacy rejection during a model test offers revocable consent for that model version and current key, followed by one retry. Declining consent after a successful chat test preserves the chat result with tools disabled. OpenRouter account restrictions still apply; no catalog-wide probes are sent.
- Route Jev and chat models separately on the server, keeping shared Jev decision logic independent of OpenRouter transport and preserving existing Jev budgets and reviewed transfers. Successful Setup tests prepare an empty or new chat without changing existing conversations, drafts or the saved default.

## Fixes

- Prevent Update Linux and other VPS actions from implicitly applying firewall or swap settings before the requested command. Remote configuration changes require the explicit Apply action; legacy or malformed requests cannot silently start a swap resize.
- Add Repair swap startup under Change VPS, using the existing protected password flow to restore a missing boot entry for an active /swapfile without resizing swap or controlling bots.
