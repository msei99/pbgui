# v2.02.5

## Added

- Added a compact one-click Compare action to collapsed PB8 Optimize validation result groups.
- Added direct links from Market Data Tiingo settings to Tiingo's API-token and authoritative usage pages.

## Security

- Removed PBGui session tokens from page source, DOM state, browser Bearer headers, and editor URLs in favor of the HttpOnly same-origin session cookie.
- Hardened page URL rendering for reverse-proxy mount paths without trusting the request host for browser WebSocket origins.
- Sanitized Help Markdown and constrained rendered links and images to safe web protocols.
- Changed Telegram alert credentials to write-only settings with explicit clearing and preservation of unchanged values.

## Validation And Limitations

- Added regression coverage for browser authentication boundaries, reverse-proxy mount paths, safe page templates, Help rendering, Telegram credential handling, and related frontend behavior.
- Final offline release suite: 7,587 passed and 41 skipped.
- No bot/VPS host was deployed, updated, restarted, or otherwise modified during development.
