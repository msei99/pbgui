# v2.11.3

- PB8 wheel validation installs `requirements-live.txt` from the verified source commit where the installed bot expects it. This restores the CCXT version check for live bots after wheel updates.
- PB8 runtime checks prefer the stamped Rust package extension over a newer duplicate module installed by the Passivbot wheel, allowing PBRun to start verified bots.
- VPS updates accept PBCoinData's clean, monitor-agent-managed idle stop during systemd verification, so a healthy PBGui update can continue to the bot update.
- PB7/PB8 VPS wheel updates can retire obsolete Rust build tools after verifying the transferred bundle and before the installation capacity check. Cleanup waits if another installed bot lacks a verified wheel runtime.
