# v1.99.8

## Fixed

- Reserved more of the OpenCode turn budget for the forced final answer by limiting ordinary read/clarification workflows to three capability rounds; explicit mutation, save, queue, and apply workflows retain ten rounds.
- Added an immediate local clarification with clickable risk-alignment choices for vague follow-ups such as `yes setup the compare`, avoiding a long Grok tool turn when exact comparison inputs are still missing.
- Added one bounded retry for transient OpenCode Responses connection failures, with a visible retry activity state and a 60-second cap per attempt; provider validation errors still fail immediately.
- Routed generated comparison risk choices directly into managed optimizer source-config Quick Replies, avoiding another provider turn while exact comparison inputs are still missing.
- Increased bounded AI conversation history from 80,000 to 512,000 characters and provider-switch handoff context from 48,000 to 256,000 characters, while retaining complete-turn trimming and finite payload safeguards.
- Resumed drawer and full-page polling for the backend continuation turn created after an approved AI action, allowing multi-step workflows to present the next proposal without a manual reload.
- Preserved the drawer's explicit provider/model selection across chat rewind instead of restoring an older conversation provider such as OpenCode.
- Delayed AI proposal cards until the matching assistant turn is complete, preventing review actions from appearing early and being rebuilt on every busy poll.
- Added path-free PB8 optimizer queue discovery and an approval-gated, restart-recoverable batch start capability for up to four exact queued jobs; queue-only results can no longer be represented as started work.
- Treated explicit German and English optimizer start requests as extended bounded action workflows so queue discovery and the start proposal have sufficient tool rounds.
- Stopped the comparison fast path from assuming two PB8 strategies: users now choose real PB7-trailing versus PB8-martingale or a PB8-only strategy comparison, and cross-generation setup lists actual PB7 source configs without substituting PB8 `trailing_grid_v7`.
- Fixed malformed PB7/PB8 branch-panel `onchange` attributes that briefly displayed a selected local branch and then reverted to the previous branch without enabling the switch action.
