# v2.09.4

## Fixes

- AI Loops now nominate promising candidates from the complete native optimizer training stream as well as the Pareto archive, using the AI's current CPU evaluation criteria and existing model capacity. Native overlay deletions are reconstructed, duplicate configurations are removed, and coverage is recorded. All nominations still require independent CPU validation; Holdout and Full Time Range remain excluded from AI evidence.
- Exact CPU training evidence now includes explicit window labels and requested/effective dates associated by report index. Reversed filesystem ordering no longer invites incorrect window attribution; ambiguous, duplicate and missing suite reports are rejected.
