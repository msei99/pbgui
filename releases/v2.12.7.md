# v2.12.7

## Reliable local service restarts

- Restore the direct GUI restart workflow: validate protected work, schedule
  outdated local services and restart the API last. Acknowledge the request only
  after scheduling succeeds. Remove the deferred restart queue.
- Drain API-owned event streams and preparation workers deterministically, and
  reject new polling temporarily during an accepted restart. Recover read access
  if the replacement cannot be signalled or its watchdog expires. Keep the live
  API module shared between script startup and service imports.
- Allow restart alongside ordinary source readers while retaining exclusive
  installer/source-writer protection and the global/API lifecycle locks. Actual
  restart admission still checks every safety gate afresh.
- Share passive REST/SSE status inspections through one owned worker, with bounded
  waits, cancellation-safe shutdown and display snapshots lasting at most 250 ms.
  Authentication remains specific to each request.
- Bound browser reconnect probes, release status streams in hidden tabs and
  preserve the current page when reconnecting. Avoid repeated restart loops.

## Startup and status corrections

- Reduce startup work without bypassing credential checks: preserve unchanged
  private-file metadata, scan managed files without following symlinks and defer
  terminal AI retention cleanup until after readiness. Log value-free timings.
- Load Pandas only for Pareto DataFrames/charts and CCXT Pro only for WebSocket
  client creation. Interrupted dependency imports remain owned and are drained.
- Accept coherent unrelated NAS automounts during PBCoinData ownership checks.
  Protected paths, ambiguous mounts and changing mount tables remain rejected.
- Fix false Wheel update warnings when legacy flat and package-layout Rust
  extensions both match the same source-bound receipt. Missing, changed or
  symlinked binaries remain rejected.

## PB9 in the VPS overview

- Show PB9 version/Python, branch/commit and GitHub status for local and remote
  hosts through the existing overview table. Preserve saved columns and count
  running bots without duplicates.
- Compare PB9 against its own official v9 upstream head through the background
  release collector, independently of PB8. No Git fetch runs in overview requests.

## Validation and limitations

All **1,329 focused offline tests passed**, including native Chromium checks.
Release validation covers restart ownership, cancellation,
source locks, authentication, private-file operations, credential migration,
PB7/PB8 installation regressions, NAS/wheel detection, PB9 overview, Pareto and
native Chromium navigation checks. No real trading process is controlled by
these tests. Fable provided bounded read-only reviews of the restart changes.

The normal GUI restart was also exercised locally during development. The last
complete measured restart took about 28 seconds; consistently finishing within
10 seconds is **not** achieved. Controlled import-only measurements improved
from a median 5.38 seconds to 4.22 seconds; this is not a full-restart benchmark.

This release publishes PBGui only. It does not update VPS hosts, change bot
assignments or restart trading processes. Load the new API code through the
normal local restart action after updating PBGui.
