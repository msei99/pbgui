# v1.96.1

- Fixed PB7 Run target selection to accept legacy VPS inventory entries when fresh monitor metadata confirms the PB7 runtime, while still excluding PB8-only and unconfirmed hosts.
- Fixed a PB7/PB8 Run editor race where a late host-capability refresh could silently revert a newly selected `Enabled On` target before saving, leading the Log panel to open an old file on a host where the bot was not restarted.
- Fixed remote native bot log streaming to switch promptly when PB7/PB8 replaces its current-log symlink, instead of leaving the frontend attached to the previous run's log for minutes.
- Fixed Hyperliquid expiry alerts on Cluster nodes to refresh only active users whose HL credentials changed, using non-secret per-user identities and bounded retries, while avoiding persistence from unsaved previews.
