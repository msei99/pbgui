# v2.10.11

## Fixes

- Services and VPS Manager no longer classify installed systemd services as requiring migration merely because they are stopped or autostart is disabled. Existing Start/Stop and Enable/Disable controls remain responsible for those settings. Missing required units and legacy startup files still require migration.
- Update the VPS systemd sidebar status automatically when monitor data changes. Completed migration previews no longer propose enabling or starting intentionally disabled/stopped services.
