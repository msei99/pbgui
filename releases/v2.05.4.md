# v2.05.4

- VPS Manager shows Hyperliquid address request usage for PB8 accounts. It samples `userRateLimit` once per unique wallet every five minutes, shows used, cap, remaining and status, and stores a 24-hour Used/Cap history that survives API restarts.
- PBv8 Run provides dedicated `live.hsl_engine` and `live.hsl_unavailable_grace_seconds` controls when the installed PB8 runtime reports those parameters. The controls populate from and save back to the V8 configuration.
