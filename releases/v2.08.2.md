# v2.08.2 — PB8 save and restart fixes

### Fixed

- PB8: A newly saved config version clears restart backoff from earlier failed starts, allowing the next supervisor cycle to start it immediately once Cluster Sync and runtime checks pass. Repeated failures of the same version retain bounded exponential backoff.
- PB8: Saving a migrated live config no longer fails when backing up a pre-v8.6 HSL config. Backups read only archival version and override references without invoking the current PB8 validator, preserving the original config and override files unchanged.

This release also includes the [v2.08.1 changes](v2.08.1.md), including the **Experimental AI Loop Optimizer**. AI Loops remain experimental.
