# v1.98.29

## Improved

- PB8 Optimize now offers every persisted numeric Pareto metric as a configurable column while lazily projecting only selected values, batching column reloads, reusing the picker DOM, and incrementally caching unchanged candidate projections.
- Pareto cache expiration now runs once per list request instead of once per candidate, reducing default payload size and substantially accelerating repeated views and statistic changes.
