# v2.05.8

- Fixed Hyperliquid limit sampling on VPS hosts without `httpx`. The monitor agent now uses Python’s standard HTTP client, so running bot wallets can populate the central limits page and history after the VPS is updated.
- The API-key editor shows the account request limit in a card beside Futures Balance, using the same card design. Saved main accounts at their cap can select and confirm a one-time request-credit purchase; vault entries show the main-account restriction.
- Hyperliquid request counters in API Keys, Hyperliquid Limits, and VPS Manager use apostrophes as thousands separators.
