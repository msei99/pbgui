# v1.99

> [!WARNING]
> **AI Development Preview:** PBGui AI is still under active development. Not every PBGui workflow is available to the agent yet, model behavior may vary by provider, and some actions or follow-up navigation can still fail. Review every proposed change carefully and rely on the explicit approval preview before allowing persistent, queued, or executable actions.

- Added owner-only persistent AI conversation history, API-owned detached turns, restart reconciliation, and a global collapsible right-side AI drawer.
- Added structured page/field context plus canonical EN/DE PBGui help tools for context-aware assistance on every authenticated top-level page.
- Added persisted owner-specific free-model health observations with manual refresh controls in the full chat and global drawer.

## Security

- Stored OpenCode Go keys in owner-only directories and files using opaque owner IDs, cross-process locking, atomic replacement, no-follow reads, and server-only use.
- Kept ChatGPT OAuth state inside owner-scoped Codex homes and explicitly hardened the directory tree to `0700` and `auth.json` to `0600` before treating an account as configured.
- Kept provider credentials out of browser storage, URLs, status payloads, diagnostics, model context, and operational logs.
