# v2.08.5

### Fixed

- Vast.ai offer searches use the canonical `/api/v0/bundles/` endpoint, avoiding HTTP 308 errors while retaining credential-safe redirect protection.
- AI Loop receives the supported cloud optimizer reducers and rejects invalid reducers such as `worst`, or conflicting reducer aliases, before preparing an optimizer job. The existing bounded decision-repair flow can then correct the proposal without silently rewriting its limits. Worst-window upper limits use `max`; worst-window lower limits use `min`.

### Limitations

- This patch does not resolve the other screenshot reports of omitted configuration fields, malformed AI JSON, optimizer exit code 1, or an incomplete approved AI action blocking API restart; their underlying run data is unavailable.
