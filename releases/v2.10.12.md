# v2.10.12

## Added

- Add **System → Storage**: disk usage per filesystem, the size of PBGui, PB7, PB8 and their Python environments, and an expandable tree of the largest folders. Folder sizes come from a low-priority background scan in its own process (default every 6 hours and when the page is opened after one hour); disk usage is live.
- Add guided cleanup in four tiers. **Safe**: rotated logs, old market data job logs, old run logs, database and DB Tools backups beyond the newest ones, DB repair leftovers. **Optional**: PB7 prepared backtest datasets, cancelled/failed cloud jobs. **Review** (entries selected individually): PB7/PB8 optimize results and backtests, completed cloud jobs, PB7 legacy `historical_data` after PB7's own migration, renamed PB7 cache folders, release worktrees, manual copies and unused PB/PBGui Python environments. **Protected**: market data, database, credentials, API keys and configurations are only shown. Every cleanup starts with a preview and a confirmation; the worker re-checks each entry on disk, skips entries that are in use (running jobs, folders changed within 24 hours, environments used by PBGui/PB7/PB8, running processes or systemd services, active cloud jobs) and reuses the Vast queue's purge and `git worktree remove`. Interrupted folder deletions finish on the next run.
- Add optional automatic retention rules for Safe and Optional categories, run once per day after a chosen hour (off by default), a daily usage history with 7/30-day growth, and a System view with CPU, memory, swap, uptime, OS, Python versions, NVIDIA GPUs and PBGui's own processes.
- Show CPU, memory, disk and uptime tiles plus free and reclaimable space on the Welcome page after login. Disk usage from 85%, low memory and high swap usage appear in the issue list with a link to Storage.
