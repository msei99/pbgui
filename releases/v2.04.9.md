# v2.04.9

## Interim fix — GPU / Vast.ai work in progress

This release extends cloud exchange and scenario support and removes the legacy 30-minute deadline restriction. It remains an interim fix: further interface work is required to clean up Settings and separate GPU / Vast.ai management from general settings.

## Changes

- Enable Bitget, OKX, Hyperliquid and KuCoin throughout Vast cloud validation, mapped OHLCV export, public market metadata and first-candle cache staging. Preserve exchange-specific CCXT identities, USDC Hyperliquid mappings and PB8 listing-history request behavior.
- Make cloud validation errors identify unsupported exchange values and allowed names, scenario numbers, labels and exact fields; display field paths directly in the editor.
- Replace the date-only cloud suite restriction with scenario-aware export: collect additional coins and exchanges, honor consistent coin_sources, deduplicate shared datasets, retain warmup history and stage metadata for every exported venue. Validate effective GPU parameter overrides and per-scenario coin limits; preserve source configs and flatten nested overrides only in frozen worker copies. Report missing mappings/history by scenario, coin and exchange. Empty optional maps and inherited exchange selections are accepted; explicit empty coin selections retain PB8 semantics.

- Remove the legacy 30-minute deadline restriction: explicitly requested adjustments upgrade only the running rental guard, verify its unchanged deadline before handover, and then acknowledge whole-minute changes without restarting the optimizer. Restore the old guard on failed handovers, retain pending requests after interrupted acknowledgements, and block API restart during migration. Keep the 60-minute default and existing budget/cleanup limits.

- Release preparation: update the displayed version and API restart serial.

## Validation

- 1,619 offline Vast and help-coverage tests passed.
- 122 focused deadline, guard migration, API restart and browser tests passed; the additional API restart-blocker test also passed.
- Guard handover and rollback were exercised with isolated local test processes; no running GPU host was modified during validation.

Restart the PBGui API and reload the page to use these changes. Existing legacy rental guards are upgraded only when a deadline adjustment is explicitly requested.
