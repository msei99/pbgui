# v2.03.1

## Fixes

- Restore VPS Manager settings-read controls with a retry message after WebSocket disconnects (#248).
- Preserve VPS Monitor pending restart/kill actions across snapshot redraws, rejecting duplicate submissions until result, timeout, or disconnect (#249).
- Restore Cluster Sync bootstrap controls after failed apply requests using the current plan and recovery-lock state, allowing retries without reloading (#250).
- Restore AI Chat composer controls after a failed Stop request so cancellation can be retried; ignore stale cancellation errors after switching chats (#265).
- Preserve already-formatted CCXT symbols in Dashboard symbol conversion, preventing malformed market names when closing positions (#272, #278).
- Index Hyperliquid DEX-prefixed metadata aliases so stock-perp symbols such as `XYZ-AAPL` resolve for candle downloads and market-data checks, without double-prefixing qualified names (#269, #275).
- Ignore non-USDT balance placeholders when reading Bitget UTA wallet balances, while retaining strict USDT and asset-list validation (#268, #274).
- Fix Bybit history pagination to stop retrying successful requests, handle empty cursor pages, and propagate exhausted or non-transient failures without returning partial history (#267, #273).
- Normalize Hyperliquid `allMids` and market metadata prices to floats so position-value calculations receive numeric prices; malformed values fall back to metadata or are skipped (#270, #276).
- Make `Exchange.fetch_balance()` raise exchange failures instead of returning exception objects as balance data, preserving existing caller error handling (#271, #277).
- Fix VPS Manager Yesterday error/traceback popups getting stuck loading by accepting yesterday requests and filtering logs by the selected UTC date (#281).
- Reject unsafe job IDs and resolved log paths outside the jobs-log directory in `GET /api/jobs/{job_id}/log`, preventing path traversal and symlink escapes (#283).
