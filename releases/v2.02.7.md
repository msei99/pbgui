# v2.02.7

## Fixed

- Fixed stale API-key editor requests and made rename-plus-update a capability-gated, crash-recoverable transaction with credential-generation-safe expiry persistence.
- Made exchange-key saves synchronously project configured local PB8 runtimes, report publication failures, and retain secure transaction-aware recovery intent. Rejected saves cannot republish stale credentials; unavailable PB7 storage is explicitly rejected.
- Invalidated cached and persisted credential expiry information after key replacement.
- Protected log viewers against stale WebSocket callbacks and duplicate subscriptions; capped snapshots, buffers, requests, and rendered history at 50,000 lines.
- Preserved partial and blank log lines across rotation-aware local cursors; synchronized API-owned console writes with purges while preserving active logfile inodes.
- Bounded logging rotation settings to 10,240 MB and 20 backups.
- Serialized service lifecycle actions and complete systemd migrations, and added an identity-safe, acknowledged direct API restart handoff.
- Prevented duplicate task workers using process-lifetime ownership, exact PID identity checks, and coordinated startup. Shutdown retains ownership until active jobs finish, including fatal-error paths.
- Protected Services Monitor polling from stale responses and duplicate actions, surfaced errors, and made manual worker-stop suppression durable.
- Restored PB7/PB8 backup rendering and rollback controls.
- Represented unavailable CoinMarketCap metrics as null, serialized native exchange symbols, and made row ordering deterministic.
- Corrected successful empty copy-trading discovery and added Coin Data quote selection with exchange-specific defaults.
- Grouped ticker requests by exchange market dimensions, bounded retries and individual recovery, and reported incomplete price coverage explicitly.
- Distinguished completed, partial, and failed refresh jobs while preserving diagnostics when page-state reconstruction fails; bounded and coalesced active refresh requests.
- Serialized exchange refresh transactions across processes and published JSON using unique temporary files, file and directory fsync, and atomic replacement.
- Corrected Hyperliquid HIP-3 normalization in confirmed mapping and fallback paths without changing global coin-name semantics.

## Validation And Limitations

- Complete offline suite for the included fixes: 7,825 passed, 41 skipped.
- PB7 remains the authoritative exchange-credential store; this release does not introduce PB8-only credential persistence.
- Publication recovery requires PBCluster and resolution of underlying storage/configuration failures.
- Unresponsive job threads retain worker ownership rather than allowing duplicate work. Raw descriptor writes from external processes do not participate in advisory log locking.
- No bot/VPS host was deployed, updated, or restarted during development or release preparation.
