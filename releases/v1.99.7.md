# v1.99.7

## Fixed

- Prevented asynchronous conversation refreshes from restoring a stale ChatGPT model after selecting OpenCode Go; model loading and unavailable states are now explicit and manual provider/model/effort selections remain stable until submitted.
- Pruned excluded build, cache, data, and virtualenv directories before Passivbot source traversal, removed per-match Git checks for dirty checkouts, and added a cooperative five-second search budget so source capabilities cannot consume the entire OpenCode turn timeout.
- Reduced normal read-only OpenCode capability loops and source-search budgets, and instructed tool models to stop repeating minor search variations once enough evidence exists; mutation/proposal workflows retain their extended round budget.
- Changed excess parallel OpenCode tool requests from a fatal turn error into bounded budget-exhausted results followed by a forced no-tools final-answer round, while retaining the 16-call execution limit across Responses, Messages, and Chat Completions protocols.
- Fixed Responses models exposing and repeatedly concatenating intermediate planning messages; PBGui now renders only the last structured assistant message and uses aggregate `output_text` only as a compatibility fallback.
