# v2.12.4

## Cluster checkpoint replay after credential-recipient updates

- Fix `compact v2 reducer basis does not match full replay` after recipient
  changes for encrypted credentials. The compact checkpoint previously selected
  records by `op_id` alone, dropping `recipient_op_id` references and the
  parent-linked recipient updates required to reconstruct the current envelope.
- Retain recipient dependencies for current and already received future provider
  generations, including temporarily unreachable branches that a later operation
  can connect. Superseded provider generations are discarded.
- Preserve migration acknowledgement dependencies whose materialized records
  omit operation IDs. Coalesce superseded acknowledgements per operation kind,
  node and freeze generation, retaining current and already received future
  freeze generations. This avoids a fallback to retaining the entire history.
- Keep exact full-replay equality checks, operation signatures, checkpoint hashes,
  replica acknowledgements, credential-migration sealing and cleanup protections
  unchanged. A genuine mismatch still pauses deletion. The checkpoint format
  remains unchanged.

## Validation and rollout

All 228 focused offline release tests passed. They cover recipient chains and
conflicts, future branches and
acknowledgements, deterministic/idempotent compaction, and a signed checkpoint
with isolated baseline-history removal followed by new operations and another
checkpoint. Fable assisted with planning and code review.

A read-only comparison against the affected Cluster's non-secret metadata
reproduced the original error and verified exact equality after the fix. Writes
and private-key/credential-store reads were blocked during that comparison.

Update PBGui on the checkpoint coordinator to activate the fix. Normal Cluster
maintenance retries checkpoint creation and retains all existing safety gates.
Do not delete checkpoint or operation files to clear the error. No remote host
was updated, no checkpoint was force-activated and no live history was deleted
while preparing this release.
