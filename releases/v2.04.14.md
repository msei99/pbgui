# v2.04.14

## Fixes
- Fix #362: allow HSL with the pinned Vast GPU worker, removing obsolete no-HSL restrictions from validation and job export while preserving HSL settings and native GPU checks.
- Remove the separate Sweep Starting balance input; generating and applying windows always reads the current general Starting balance.
- Remove the redundant scenario Recalculate action: Generate windows calculates and displays the current plan directly without reverting to previously applied windows.
- Show green outer boundary lines at the first scenario window start and last window end in the shared Backtest/Optimize chart.
- Use one shared date-input renderer and overwrite behavior in Backtest, Optimize, and re-backtest dialogs. Backtest now loads the shared component; commit overwritten values on blur so change handlers and manual-date semantics (including clearing `now`) run reliably.

## Known limitations
- Date-input audit: scenario overrides, Strategy Explorer analysis/movie dates, DB cleanup cutoff, Tiingo start date, and Hyperliquid build dates still lack the shared digit-overwrite behavior. Native browser date controls in dashboards and market-data tools also remain separate implementations; their editing behavior was not browser-tested in this audit.
