## Upgrade notes

- Claude is optional and requires Node.js 22+ and the pinned local runtime. Install it from the PBGui directory with `npm ci --prefix runtime/claude_agent`, then use **Information → AI Setup → Claude Agent → Sign in with Claude**. Existing providers keep working without this installation.

No Anthropic API key is required or imported. (#445)
