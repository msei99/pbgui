# v2.03.6

- Reduced vertical padding in Profit Sweep overview account rows for a more compact table.

- Confirmed Profit Sweep Live activations now finish independently of sidebar account changes. Per-account progress and failures remain visible in the sidebar, successful activations update the correct account, duplicate activation clicks are blocked, and stale policy reads cannot overwrite completed activations.

- Added a Refresh now button to the Profit Sweep overview header. It queues balance reads through the existing paced background workers; repeated requests within a minute are combined and no sweep evaluation or transfer is triggered.

- Profit Sweep immediately queues one paced background refresh for legacy Hyperliquid cache entries without a target-wallet identity, so USDC target totals do not wait for the normal interval. The attempt is persisted, including failures, preventing repeated backfill requests on every scheduler tick or API restart.

- Added a Profit Sweep overview summary for visible accounts, with separate currencies and simulated totals, unique destination-wallet balances and explicit partial totals. The header's Anonymize accounts checkbox replaces visible account names (including the overview sidebar) with stable session aliases while preserving amounts and account navigation.

- Profit Sweep overview defaults to a 15-minute background balance refresh, configurable in the header (5/15/30/60 minutes) and persisted across restarts. Removed the update footer; stale indicators follow the selected interval and old one-minute cache delays are ignored.

- Hardened Profit Sweep overview refreshes: Hyperliquid uses balance-only reads instead of full history/preflight snapshots, shares vault destination reads, paces requests, retries transient errors with bounded backoff and a shared HTTP 429 cooldown, and slows repeated failures. Partial refreshes retain each balance with its own original timestamp; transfer preflights remain unchanged.

- Profit Sweep overview no longer reports an unsupported account mode when the mode lookup itself failed; transient lookup failures retain their actual read-error diagnosis.

- Profit Sweep overview aligns account names, mode badges and assets in fixed positions. Snapshot failures now retain safe error codes and sources in status tooltips and logs; unsupported account modes are identified separately from read failures, while successfully read balances remain visible.

- Profit Sweep now opens a compact account overview from the standard sidebar button, showing mode, visible status, source/target balances, Net PnL, swept totals and sweep due. A persistent background balance cache keeps page loads independent of exchange latency; rows include freshness and accounting tooltips, explicit Dry totals and keyboard navigation.
